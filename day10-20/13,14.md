## Today's Theme
Users and Groups 

## What I Learned
- `/etc/login.defs` に新規ユーザー/グループの UID・GID の範囲（通常 1000〜60000）が定義されている
- `getent group {1000..6000}` のようにブレース展開で範囲指定して一覧確認できる
- グループ操作: `groupadd` 追加 / `groupmod -n 新名 旧名` リネーム / `groupdel` 削除
- ユーザー操作: `adduser`（対話的、ホームディレクトリ作成あり）vs `useradd`（低レベル、自動セットアップなし）
- `adduser --ingroup グループ名 ユーザー名` で作成と同時にプライマリグループを指定できる
- `usermod -g グループ` でプライマリグループ変更、`usermod -aG グループ` で補助グループ追加（`-a` を忘れると既存の補助グループから外れる）
- `usermod -l 新名 旧名` でユーザー名のリネーム
- `chgrp グループ ファイル` でファイルのグループ所有者を変更
- `chmod g+w ファイル` でグループに書き込み権限を付与（記号表記）
- ユーザーが sudo 権限を持つには `/etc/sudoers` への記述 or `sudo` グループ所属が必要
- sudoers の編集は **必ず `visudo`**（構文チェックしてくれる）
- sudoers の構文: `ユーザー ホスト=(実行ユーザー:実行グループ) コマンド`、`=` であって `-` ではない

## Commands Used
```bash
# UID/GID の範囲を確認
grep GID /etc/login.defs
grep UID /etc/login.defs

# グループ一覧（UID/GID 範囲指定）
getent group {1000..6000}
getent passwd {1000..60000}

# グループの作成・リネーム・削除
sudo groupadd kame
sudo groupadd tsuru
sudo groupmod -n saiya kame    # kame → saiya にリネーム
sudo groupdel tsuru

# ユーザー作成（adduser は対話的）
sudo adduser goku
sudo adduser --ingroup saiya vegeta    # 作成と同時にプライマリグループ指定
sudo adduser krillin
sudo adduser dende

# ユーザー削除
sudo userdel goku

# ユーザーのグループ変更
sudo usermod -g saiya goku       # プライマリグループ変更
sudo usermod -aG earth goku      # 補助グループ追加（-a 必須）
sudo usermod -g earth krillin
sudo usermod -g namek dende

# ユーザー名・グループ名のリネーム
sudo usermod -l kakarot goku     # goku → kakarot
sudo usermod -l god dende        # dende → god
sudo groupmod -n temple namek    # namek → temple

# 確認系
groups goku vegeta
groups dende
cat /etc/passwd

# ユーザー切り替え
sudo su vegeta
whoami
exit

# 権限・所有者の変更
sudo chmod 755 /home/krillin     # 他ユーザーから入れるように
sudo chgrp earth goku            # ファイル goku のグループを earth に
sudo chmod g+w goku              # グループに書き込み権限付与

# umask 確認
umask
umask -S    # シンボリック表記で表示

# sudoers の編集
sudo visudo
```

## Where I Got Stuck

**問題1: `/home/krillin` に cd できなかった**
- `cd: /home/krillin/: Permission denied`
- 原因: krillin のホームは `drwx------`（700）で、所有者本人以外は入れない
- 解決: `sudo chmod 755 /home/krillin` で他ユーザーからも入れるように変更
  - or `sudo -i` で root になって作業

**問題2: vegeta で sudo が使えなかった**
- `vegeta is not in the sudoers file.`
- 原因: vegeta は sudo グループに入っておらず、sudoers にも記述がない
- `sudo visudo` 自体も sudo 権限がいるのでデッドロック → 一度 exit してメインユーザーに戻る必要があった

**問題3: visudo で構文エラー**
- `/etc/sudoers:48:12: syntax error` → `vegeta ALL-(ALL:ALL) ALL`
- 原因: `=` を書くべきところを `-` にしていた
- 解決: `What now?` プロンプトで `e` を押して再編集 → `-` を `=` に修正
- `Q`(強制保存)を選ぶと sudo 自体が壊れて復旧が面倒になる。必ず `e` で直す

## Insights & Reflections
権限系は少しのミスが大きい問題になる可能性があるので、構文などをチェックする必要があると思った。
